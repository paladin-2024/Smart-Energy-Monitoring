Hardware & Circuit Design

ESP32 WROOM-32 simulation on Wokwi with real-time sensor reading, OLED display, and overload protection.

Components

ESP32 WROOM-32

Main MCU — dual-core, WiFi/BT, 34 GPIO

SSD1306 OLED

128×64 monochrome I2C display (0x3C)

ACS712 Sensor

Hall-effect current sensor (simulated via ADC)

Potentiometers ×2

Simulate voltage & current on GPIO34/35

Green LED

SAFE status indicator (GPIO25)

Red LED

OVERLOAD alert indicator (GPIO26)

Buzzer

Audible overload alarm (GPIO27)
